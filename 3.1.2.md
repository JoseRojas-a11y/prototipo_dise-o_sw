# 3.1.2. Módulo 2 / Integrante 2 (ROJAS)

### Módulo 3: Gestión de Incentivos y Fidelización (Gamificación)
- **Actor principal:** Comprador / Visitante, Validador / Personal de Campo, Comerciante.
- **Descripción del módulo:** Administra la asignación de puntos por reportes confirmados, el índice de reputación de los colaboradores y el canje de beneficios comerciales en tiendas aliadas.

| ID | Requisito Funcional | Descripción Específica | Actor(es) | RN Relacionada | Prioridad |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RF-301** | Asignación y acumulación de puntos por validación | El sistema debe acreditar puntos en la cuenta del usuario tras la confirmación satisfactoria de un reporte de precio, stand o producto en campo. | Sistema | RN-03, RN-01 | Alta |
| **RF-302** | Cálculo del índice de reputación del validador | El sistema debe recalcular dinámicamente un nivel de confianza del colaborador con base en el ratio de reportes aprobados frente a los rechazados. | Sistema | RN-01 | Media |
| **RF-303** | Catálogo y canje de cupones y descuentos | El sistema debe desplegar las promociones y vales de descuento vigentes ofrecidos por tiendas aliadas, permitiendo al usuario redimir sus puntos por un código único de canje. | Comprador / Visitante | RN-03 | Alta |
| **RF-304** | Validación de cupones en punto de venta | El sistema debe permitir al comerciante verificar y consumir el código de descuento presentado por el comprador mediante lectura o código alfanumérico. | Comerciante | RN-03 | Alta |

### Módulo 7: Administración y Gobernanza Centralizada/Híbrida
- **Actor principal:** Administrador del Sistema.
- **Descripción del módulo:** Agrupa los paneles maestros de auditoría, control de accesos, resolución de discrepancias sobre información de stands y parametrización de directrices globales del sistema.

| ID | Requisito Funcional | Descripción Específica | Actor(es) | RN Relacionada | Prioridad |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RF-701** | Gestión centralizada de usuarios y roles | El sistema debe permitir al administrador crear, suspender, reactivar y asignar permisos a los distintos roles operativos de la plataforma. | Administrador del Sistema | — | Alta |
| **RF-702** | Panel maestro de resolución de disputas de datos | El sistema debe proveer una consola para auditar discrepancias entre reclamos de comerciantes y reportes comunitarios, permitiendo aprobar o revertir cambios en el catálogo oficial. | Administrador del Sistema | RN-01 | Alta |
| **RF-703** | Configuración de parámetros globales del sistema | El sistema debe permitir modificar las tasas de conversión de puntos, umbrales de reputación mínima y límites de vigencia de las campañas publicitarias. | Administrador del Sistema | RN-03 | Media |
| **RF-704** | Registro de auditoría y trazabilidad de operaciones | El sistema debe almacenar bitácoras inmutables de todas las altas, bajas y modificaciones realizadas sobre puestos, transacciones monetarias y canjes de puntos. | Sistema | — | Alta |
