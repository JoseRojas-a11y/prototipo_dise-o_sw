# ADR-403: Foto como input file con preview local

Fecha: 2026-09-30
Módulo: 4 - Ingesta y Actualización de Datos
Autor: Renzo Moises Chavarria Llamacponcca
Estado: Aceptado

## Contexto
La zona dashed `Tomar foto o subir` hoy no abre selector y no muestra preview.

## Decisión
Input file oculto + `FileReader` para preview inmediato, sin subir a servidor. Texto guía `fondo claro o percha del stand`.

## Alternativas
1. Subida real a S3 — descartada para prototipo.
2. Sin foto obligatoria — descartada, la vitrina exige foto.

## Consecuencias
+ Vendedor ve su prenda al instante.
- Foto se pierde al recargar.

## Atributos de calidad
Usabilidad, Rendimiento.
