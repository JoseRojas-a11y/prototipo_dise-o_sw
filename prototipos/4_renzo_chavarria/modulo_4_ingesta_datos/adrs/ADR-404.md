# ADR-404: Precios duales unidad vs docena mayorista

Fecha: 2026-09-30
Módulo: 4 - Ingesta y Actualización de Datos
Autor: Renzo Moises Chavarria Llamacponcca
Estado: Aceptado

## Contexto
Gamarra vende por docena. Confundir precio unidad con mayor rompe la comparación.

## Decisión
Dos campos separados: `Precio x Unidad` y `Precio x Mayor / Doc` destacado en verde `#006c49`. Docena obligatoria para indexar en M2.

## Alternativas
1. Precio único — descartado por no reflejar negocio real.
2. Cálculo automático doc = unidad*12 — descartado, el mayor tiene descuento propio.

## Consecuencias
+ Claridad para comprador de provincia.
- Requiere validar doc < unidad*12.

## Atributos de calidad
Exactitud dominio, Usabilidad.
