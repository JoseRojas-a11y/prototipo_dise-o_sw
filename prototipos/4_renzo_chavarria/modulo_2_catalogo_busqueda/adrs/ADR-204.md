# ADR-204: Ficha de producto con comentarios simulados

Fecha: 2026-09-30
Módulo: 2 - Búsqueda y Catálogo Comercial
Autor: Renzo Moises Chavarria Llamacponcca
Estado: Aceptado

## Contexto
Se necesita validar comunicación mayorista (Huancayo, Arequipa, Cusco) sin backend ni WhatsApp real.

## Decisión
Simular en `detalle_producto_comentarios`: filtros Todos/Con foto/Pendientes en JS, botones Responder/WhatsApp muestran toast `Respuesta enviada`, input Respuesta Oficial hace append local.

## Alternativas
1. Integrar WhatsApp API real — descartada, fuera de alcance prototipo.
2. Comentarios estáticos sin interacción — descartada por flujo tosco.

## Consecuencias
+ Experiencia completa para video sin login ni backend.
- Datos no persisten al recargar.

## Atributos de calidad
Usabilidad, Prototipado rápido.
